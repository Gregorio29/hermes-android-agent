# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a vulnerability or permission bypass in the Android automation controller:

1. **Do not create a public issue.**
2. Report the vulnerability privately via GitHub Security Advisories.
3. Maintainers will respond promptly.

## Security Levels
This library enforces action security classifications (`SAFE`, `REVERSIBLE`, `SENSITIVE`, `DESTRUCTIVE`). Ensure sensitive operations are authorized before execution.
